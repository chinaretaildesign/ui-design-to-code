# ui-design-to-code

从产品想法生成**指定风格的高保真 UI 视觉稿**，确认后再转代码的 AI Skill。让不懂代码的用户先用图像确认产品长什么样、交互怎么走，避免直接写代码后大返工。

## 能做什么

- 快速 vibe 一个 APP / 网页 / 小程序界面
- 从模糊口语需求翻译成准确 UI 术语（如「鼠标放大一点」→「悬停抬起 + 邻位让位」）
- 生成统一风格（可爱风 / 清新 / 科技感 / 极简）的高保真 UI 概念稿
- 内置 UI 质检清单：对比度、字号层级、间距、裁切、文字异常、组件一致性、跨页连续
- 确认后再谈代码落地

## 工作流

1. **收集输入**：产品类型、目标用户、平台、页面需求、视觉风格
2. **需求术语化**：把模糊口语翻译成准确 UI/交互术语，复述确认
3. **梳理页面清单 + 用户操作旅程**
4. **一次定好整页配色 / 间距 / 层级规范**
5. **组织视觉展示板**
6. **用 ImageGen 生成统一风格高保真 UI 稿**
7. **UI 质检**（对比度/字号/层级/间距/裁切/文字/组件一致性/跨页连续）
8. **展示并等待确认 → 确认后再转代码**

## 使用方式

把本目录作为 Skill 安装到你的 AI 工作台（豆包 / Codex / Claude 等支持 Skill 的环境），然后直接描述你想做的 APP：

> 「做一个旅游 APP，用户能浏览景点攻略、规划行程、查看签证信息，风格走清新自然」

它会按上面 8 步出 UI 稿，等你确认后再转代码。

## 风格快速参考

| 风格 | 关键词 |
| --- | --- |
| 可爱风 | 糖果色、大圆角、圆润粗体、贴纸/毛绒质感、表情元素 |
| 清新自然 | 低饱和绿/蓝、留白、细字体、圆角适中 |
| 科技感 | 深色底、霓虹/渐变点缀、细线、发光、毛玻璃 |
| 极简 | 黑白灰、大留白、无衬线细字、极简图标 |
